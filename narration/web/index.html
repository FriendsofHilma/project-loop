How this was made, and what it is not.
  • Engine: Piper 1.8.0, offline on CPU. Code MIT; the LibriTTS voice dataset is CC BY 4.0.
  • No voice cloning, no reference audio, no author recording. If a recording is supplied later, it becomes a separate, consented provider — not a silent substitution.
  • Windows SAPI is available (Microsoft Zira Desktop only) as a fallback; edge-tts is disabled because redistribution rights are unclear.
  • Canonical text is hashed into each track's JSON metadata. Pronunciation respelling is applied to the synthesis input only.
  • Regenerate one passage with python narration/tools/narrate.py segment --track narration/output/ch01_story.json --index 2.
